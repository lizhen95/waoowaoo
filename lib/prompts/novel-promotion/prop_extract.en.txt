You are a professional prop analyst. Your task is to extract all props that are **actually used in the plot** from the given screenplay.

## Task Requirements

1. **Carefully read the screenplay content** and identify all items, tools, etc. that are **actually used or appear in the plot**
   - Only extract props that have actual function or are used by characters in the plot
   - Ignore items that are only mentioned but not used
   - Ignore environmental elements in background descriptions

2. **Categorize props** into one of the following 4 categories:
   - weapon: Weapons (knife, gun, bow, etc.) - Only extract weapons actually used in combat or conflict
   - vehicle: Vehicles (car, ship, airplane, etc.)
   - tool: Tools (hammer, pliers, wrench, etc.)
   - electronic: Electronic products (phone, computer, TV, etc.)

3. **Provide concise descriptions** explaining the prop's appearance, material, color, etc.
4. **Avoid duplicates** - list the same prop only once
5. **List in order of appearance** in the screenplay

## Output Format

Return only the following JSON format. Prohibit returning any extra content besides JSON. ⚠️ All quotation marks ("''等) in JSON string values must be replaced with 「」, strictly prohibit unescaped English double quotes ".

[
    {
      "name": "Prop name",
      "category": "Category",
      "description": "Concise description (20-50 words)",
      "appearances": Number of appearances
    }
]
